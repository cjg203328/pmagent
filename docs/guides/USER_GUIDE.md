## 项目简介

### 这是什么？

**ArtPM Agent** 是一个专门为游戏美术外包项目管理设计的智能助手，基于 Streamlit 构建，核心特点是**离线优先**设计。

### 核心理念

- 🎯 **垂直领域专家**：专注美术外包项目全生命周期管理
- 🔌 **离线优先**：核心业务功能无需 API 密钥
- 🤖 **AI 增强**：配置 API 后解锁智能对话能力
- 📊 **数据驱动**：基于 SQLite 业务数据库和 FAISS 向量检索

### 技术栈

```
前端：Streamlit (Python Web 框架)
后端：Python 3.10+
数据库：SQLite (业务数据 + 对话历史)
向量检索：FAISS (工作区知识库)
AI 模型：支持 Anthropic Claude / OpenAI GPT / 自定义 API
```

### 项目统计

- 📄 Python 文件：126 个
- 🎯 核心技能：9 个内置技能
- 📚 文档：15+ 个 Markdown 文档
- 💾 数据库：3 个（业务 + 对话 + 向量）

## 快速开始

### 1. 启动应用

#### Windows（推荐）

```bash

## 核心功能

### 🎯 离线功能（无需 API Key）

#### 1. 利润测算

**输入**：
```
报价12万成本8万帮我算利润
```

**返回**：
- 毛利润：4万
- 毛利率：33.33%
- 管理费、税费、风险储备扣除后的净利润
- 详细成本结构分析

#### 2. 任务分配

**输入**：
```
分配建模任务给团队成员
```

**返回**：
- 基于技能匹配度的推荐
- 成员当前负载分析
- 经验水平评估
- 建议分配方案

#### 3. 进度检查

**输入**：
```
检查项目进度有没有卡住的
```

**返回**：
- 截止日期临近的项目预警
- 当前进度状态
- 风险项目识别
- 建议采取的行动

#### 4. 文档解析

**操作**：
1. 点击"上传文档"按钮
2. 选择 Excel 报价单（.xlsx / .xls）
3. 输入：`解析这份报价单`

**返回**：
- 自动提取报价金额、客户信息
- 识别任务类型和数量
- 生成结构化数据
- 保存到数据库

#### 5. 文件工具（MCP）

**输入**：
```
搜索项目中包含"角色建模"的文件
分析最近7天的项目数据
```

**功能**：
- 文件搜索（支持通配符）
- 内容搜索（全文检索）
- 目录列表
- 文件读取
- 统计分析

#### 1. 智能对话

配置 API 后，可以进行自然对话：

帮我分析一下最近三个月的项目利润趋势

用户：我们公司建模师日薪是1000元

用户：（下次）计算这个项目的成本
AI：基于您之前设置的建模师日薪1000元...
```

## 使用场景

### 场景 1：快速报价评估

**场景描述**：收到客户报价单，需要快速评估利润空间。

**操作流程**：

1. **上传报价单**
   - 点击"📎 上传附件"
   - 选择客户的报价单（Excel/PDF）

2. **解析文档**
   ```
   解析这份报价单
   ```

3. **计算利润**
   ```
   报价金额 [从解析结果获取]
   预估成本 [输入你的成本估算]
   帮我算利润
   ```

4. **查看结果**
   - 毛利润、毛利率
   - 扣除管理费后净利润
   - 税费计算
   - 风险储备建议

**时间成本**：< 2 分钟

---

### 场景 2：任务分配

**场景描述**：新项目启动，需要分配任务给合适的团队成员。

**操作流程**：

1. **输入需求**
   ```
   我有一个角色建模任务
   需要高级别建模师
   预计工期2周
   帮我分配给合适的人
   ```

2. **查看推荐**
   - 系统会推荐技能匹配的成员
   - 显示每个人当前负载
   - 给出优先级排序

3. **确认分配**
   ```
   分配给 [成员名字]
   ```

**智能因素**：
- ✅ 技能匹配度
- ✅ 经验水平
- ✅ 当前工作负载
- ✅ 历史完成质量

---

### 场景 3：进度监控

**场景描述**：每周一检查所有项目进度，识别风险。

**操作流程**：

1. **全局检查**
   ```
   检查所有项目进度
   ```

2. **查看预警**
   - 红色：截止日期 < 3 天
   - 黄色：截止日期 3-7 天
   - 绿色：正常

3. **详细分析**
   ```
   分析 [项目名] 的延期原因
   ```

4. **采取行动**
   ```
   给出 [项目名] 的加速建议
   ```

**时间成本**：5-10 分钟/周

---

### 场景 4：项目复盘

**场景描述**：项目交付后，总结经验教训。

**操作流程**：

1. **生成复盘**
   ```
   帮我复盘 [项目名称]
   ```

2. **查看分析**
   - 成本实际 vs 预算
   - 工期实际 vs 计划
   - 利润率分析
   - 团队表现
   - 问题与改进

3. **记录知识**
   ```
   把这个经验加入工作区知识
   ```

**价值**：
- 📈 持续改进
- 📚 知识沉淀
- 🎯 未来项目参考

## 高级功能

### 1. 工作区知识管理

#### 什么是工作区知识？

系统会记住你的：
- 业务规则（"我们的建模师日薪是1000元"）
- 项目经验（"这个客户喜欢日系风格"）
- 决策偏好（"优先分配给有经验的成员"）

#### 如何添加知识？

**方式1：直接告诉AI**
```
记住：我们公司的管理费率是15%
```

**方式2：从对话中提取**
```
AI: 我建议将管理费率设为15%
用户: 采纳这条建议

AI: 已加入工作区知识，后续会参考

**方式3：从文档中学习**

用户: 确认
```

## 常见问题

### Q1: 必须配置 API Key 才能使用吗？

**A:** 不需要！核心业务功能都是离线的：

✅ **无需 API Key 即可使用**：
- 利润测算
- 任务分配
- 进度检查
- 文档解析
- 文件工具

❌ **需要 API Key 才能使用**：
- 智能对话
- 语义理解
- 工作区知识提取

---

### Q2: 如何配置 API Key？

**步骤**：

1. **编辑配置文件**
   ```bash
   # 复制示例配置
   cp .env.example .env
   
   # 编辑配置
   notepad .env  # Windows
   nano .env     # Linux/Mac
   ```

2. **填入密钥**
   ```env
   # Anthropic Claude（推荐）
   LLM_PROVIDER=anthropic
   ANTHROPIC_API_KEY=sk-ant-your-key-here
   
   # 或 OpenAI GPT
   LLM_PROVIDER=openai
   OPENAI_API_KEY=sk-your-key-here
   
   # 或自定义API（如 DeepSeek）
   LLM_PROVIDER=custom
   LLM_MODEL=deepseek-v4-flash
   OPENAI_API_BASE=https://api.your-provider.com/v1
   OPENAI_API_KEY=sk-your-key-here
   ```

3. **重启应用**
   ```bash
   restart.bat  # Windows
   ```

4. **验证**
   ```
   # 在对话框输入
   你是谁？
   
   # 如果返回AI回复，说明配置成功
   ```

### Q3: 数据存储在哪里？

**位置**：`data/` 目录

```
data/
├── artpm.db              # 业务数据（项目、任务、成员）
├── conversations.db      # 对话历史
├── episodes.db           # Agent 执行记录
├── vector_store/         # 工作区知识向量库
├── chat_attachments/     # 上传的附件
└── backups/              # 数据库备份
```

**备份**：
```bash
# 手动备份
python scripts/backup_data.py

# 自动备份（每天）
# 保留最近 7 份备份
```

### Q4: 如何清理数据？

**清理对话历史**：
- 在设置页 → 对话管理 → 清理历史对话
- 或手动删除 `data/conversations.db`

**清理工作区知识**：
- 在设置页 → 工作区知识 → 清空知识库
- 或手动删除 `data/vector_store/`

**完全重置**：
```bash
# 删除所有数据（谨慎！）
rm -rf data/
# 应用会自动重新初始化
```

### Q5: 应用很慢怎么办？

**可能原因**：

1. **API 响应慢**
   - 切换到更快的模型（如 `claude-3-5-haiku`）
   - 或切换提供商

2. **向量检索慢**
   - 工作区知识太多
   - 清理不需要的知识

3. **数据库太大**
   - 清理旧对话历史
   - 运行数据库优化

**优化命令**：
```bash
# 优化数据库
python scripts/optimize_db.py

# 清理缓存
rm -rf __pycache__ artpm_agent/__pycache__
```

### Q8: 遇到错误怎么办？

**查看日志**：
```
artpm_agent/logs/artpm_YYYYMMDD.log
```

**常见错误**：

1. **ModuleNotFoundError**
   ```bash
   # 重新安装依赖
   python -m pip install -e .
   ```

2. **Database is locked**
   ```bash
   # 停止所有Streamlit进程
   taskkill /F /IM streamlit.exe  # Windows
   pkill -f streamlit             # Linux/Mac
   ```

3. **API Key invalid**
   - 检查 `.env` 文件中的密钥
   - 确认密钥有效且有余额

4. **Port already in use**
   ```bash
   # 使用其他端口
   streamlit run artpm_agent/app.py --server.port 8502
   ```

**获取帮助**：
- 查看 `README.md`
- 查看相关文档（如 `FAKE_PAGES_FIX.md`）
