AgentSession 生命周期；附件管道（视觉预处理 + 文档解析）；知识规则处理器；运行时契约 HarnessRuntime。

基础设施

providers/ · runtime/

ModelGateway：故障转移、响应缓存（按工作区隔离）、模型健康追踪。AgentLoop：工具调用、Token 预算、结构化审批。

基础设施

memory/

跨会话向量记忆（FAISS IVF/Flat 自适应）、对话压缩器、记忆注入器、情节存储、反馈存储。辅助 store 不再泄漏主 schema。

基础设施

tenancy/ · security/

请求级多租户隔离：TenantContext（frozen dataclass）、WorkspaceStoreGuard 拦截跨工作区写操作。permission_preflight 挂在工具调用前。

基础设施

api/ · FastAPI

REST 网关（port 8765）；语音会话、工作流、权限端点。依赖注入工厂模式；端口冲突时 Streamlit 独立运行不受影响。

基础设施

plugins/ · workflows/

基于 artpm-plugin.json manifest 的外部技能加载器（SHA-256 校验）。LangGraph 任务协调器 + 可视化工作流设计器。

UI

views/ · voice/

Streamlit 页面：chat（租户上下文 + 语音回复）、settings（框架 / MinerU / 插件管理）、observability（遥测 + 缓存命中率）。LiveKit 语音通道可选。

关键设计决策
D · 01

多租户隔离：请求级而非进程级

TenantContext 是 frozen dataclass，通过 contextvars 绑定到请求。WorkspaceStoreGuard 在每次写操作前强制校验，违规抛 WorkspaceAccessDenied。bind_inputs() 覆写模型提供的 scope，信任根在服务端。现阶段是基础防护，完整 SaaS 级多租户标注为后续改进项。

tenancy/WorkspaceStoreGuardTenantContext
D · 02

LangChain 作为适配器，非主控制流

AgentLoop、审批门、记忆管道、provider 故障转移都是应用自有边界，LangChain 仅用于结构化 provider 桥接。LangGraph 处理有状态任务图编排。避免框架锁定；离线模式不受 LangChain 缺失影响。

LangChainClientLangGraphTaskOrchestratorproviders/
D · 03

插件系统：操作员可信代码，非沙箱

插件通过 artpm-plugin.json（schema_version=1）声明，加载需 6 条件同时满足：启用标志、ID 在 allowlist、SHA-256 校验通过、risk 合法、read_only=false 时必须 requires_approval=true。PluginManager 由服务端创建注入 context，外部代码无法自注册。

plugins/manifest.pyPluginPolicyPluginManager
D · 04

MinerU：fail-open 可用性，fail-closed 安全性

CLI 缺失、超时、JSON 非法 → 回落内置解析器（fail-open）。路径穿越、符号链接、超大 archive、输出溢出 → 拒绝不索引（fail-closed）。缓存键含输入 SHA-256 + 后端版本，升级自动失效。远端端点强制 HTTPS（loopback 除外）。

mineru_adapter.pyartpm-mineru-v1
D · 05

响应缓存：按工作区隔离的规范化键

旧实现用 _norm() 拼接字符串，两个不同对话可能碰撞同一键；图片以临时路径作键而非内容。新实现：键为 NFC 规范化 JSON（排序键、折叠 CRLF、history 只保留 role/content/name/tool_call_id），schema 标签 response-v2，namespace 从 TenantContext 派生（tenant_id:workspace_id），永不信任调用方传入的 scope。L1 有界内存缓存始终存在；Redis L2 可选；缓存层异常被吞掉，不中断正常回复。
