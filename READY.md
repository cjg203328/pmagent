## Configuration

Edit `.env`:

```env
OPENAI_API_KEY=sk-your-key
ANTHROPIC_API_KEY=sk-ant-your-key
```

## Manual Start

```bash
pip install streamlit pandas plotly sqlalchemy openpyxl
streamlit run artpm_agent/app.py
```
