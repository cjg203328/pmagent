# ArtPM Copilot - 快速启动指南

## 🚀 启动Web界面

游戏美术资产PM智能助手现已支持现代化Web界面！

### 方式一：Web界面 (推荐)

```bash
python -m streamlit run artpm_agent/app.py
```

访问 http://localhost:8501 即可使用

### 方式二：命令行界面

```bash
python -m artpm_agent.main
```

## 📋 前置条件

### 1. 安装Python依赖

```bash
pip install -r requirements.txt
```

### 2. 配置API密钥

复制 `.env.example` 为 `.env`:

```bash
cp .env.example .env
```

编辑 `.env` 文件，填入你的API密钥:

```env
# 使用 Anthropic Claude (推荐)
LLM_PROVIDER=anthropic
ANTHROPIC_API_KEY=sk-ant-your-key-here

# 或使用 OpenAI GPT
# LLM_PROVIDER=openai
# OPENAI_API_KEY=sk-your-key-here
```

## 🎨 Web界面功能

### 💬 智能对话
- 类似Kimi的对话界面
- 实时AI响应
- 对话历史记录

### 📄 文档上传
- 拖拽上传报价单
- 支持 Excel、图片、PDF
- 自动识别文档类型
- 智能提取关键信息

### 📊 项目看板
- 实时监控项目进度
- 关键指标可视化
- 任务状态追踪

### 💰 利润分析
- 自动计算毛利率、净利率
- 成本构成分析
- 历史数据对比

### 👥 任务分配
- 智能匹配团队成员
- 负荷均衡分析
- 技能匹配度评估

## 🎯 快速上手

1. **启动应用**
   ```bash
   python -m streamlit run artpm_agent/app.py
   ```

2. **选择功能**
   - 点击左侧边栏的快捷按钮
   - 或直接在对话框输入需求

3. **上传文档**
   - 点击"上传报价文档"
   - 拖拽文件或选择文件
   - 等待AI自动解析

4. **查看结果**
   - 自动识别文档类型
   - 提取结构化数据
   - 计算利润分析

## 🛠️ 技术特性

- **现代化UI**: 基于Streamlit的深色主题界面
- **实时交互**: 流式对话体验
- **可视化看板**: 项目进度、利润分析图表
- **智能识别**: OCR + LLM双引擎文档解析
- **记忆系统**: RAG检索历史项目数据

## 🎨 界面设计

- **深色主题**: 专业的深蓝色渐变背景
- **高对比度**: 青色强调色 (#38BDF8)
- **卡片化布局**: 清晰的信息分组
- **响应式设计**: 适配不同屏幕尺寸
- **流畅动画**: 按钮悬停、页面切换动效

## 🔧 自定义配置

编辑 `config_data/default_config.json` 可以调整:

- LLM模型和参数
- 成本配置（人员等级单价）
- 任务分配策略
- 进度预警阈值
