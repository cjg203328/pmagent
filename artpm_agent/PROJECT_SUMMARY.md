# ArtPM Copilot - 项目总结

## 📦 项目概述

**ArtPM Copilot** 是一个专为游戏美术资产项目经理打造的智能Agent系统，采用现代化Web界面，帮助PM自动化处理报价测算、任务分配、进度追踪等重复性工作。

## 🛠️ 技术栈

| 层级 | 技术 | 说明 |
|------|------|------|
| **前端** | Streamlit | 快速Web界面开发 |
| **Agent** | 自研ReAct | 意图识别+技能调度 |
| **LLM** | Claude 3.5 / GPT-4o | 主推理模型 |
| **数据库** | SQLite | 轻量级结构化存储 |
| **向量库** | FAISS | 语义检索 |
| **OCR** | PaddleOCR | 图片文档识别(预留) |
| **PDF解析** | pdfplumber | PDF提取(预留) |
| **语言** | Python 3.10+ | 核心开发语言 |

## 🚀 快速启动

### 方法一: 一键启动 (推荐)
```bash
# Windows
双击 start.bat

# Mac/Linux
bash start.sh
```

### 方法二: 手动启动
```bash
# 1. 安装依赖
pip install -r requirements.txt

# 2. 配置API密钥
cp .env.example .env
# 编辑 .env, 填入 ANTHROPIC_API_KEY 或 OPENAI_API_KEY

# 3. 启动Web界面
streamlit run app.py

# 或启动CLI界面
python main.py
```

### 方法三: Docker启动 (待实现)
```bash
docker-compose up
```

## 📝 使用示例

### 示例1: 智能对话
```
用户: 你好，介绍一下你的功能
AI: 您好！我是ArtPM Copilot，专为游戏美术项目经理设计。
    我可以帮您:
    1. 自动识别和解析报价文档
    2. 计算项目利润和成本分析
```
