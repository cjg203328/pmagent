## 🎨 配色方案

### 主色调
```css
背景色:
- 主背景: #0B0E14 → #1E293B (深蓝渐变)
- 侧边栏: #0F172A (深海蓝)
- 卡片背景: #1E293B (深板岩)

强调色:
- 主强调: #38BDF8 (天蓝色)
- 次强调: #22D3EE (青色)
- 行动色: #F97316 (橙色)

文字色:
- 主文字: #F8FAFC (近白色)
- 次文字: #94A3B8 (浅灰)
- 边框: #334155 (深灰)
```

### 状态颜色
```css
成功/运行中:  #22D3EE (青色)
警告:         #F97316 (橙色)
错误/危险:    #EF4444 (红色)
```

## 💡 交互设计

### 按钮效果
- 悬停: 向上平移2px + 阴影
- 渐变背景: 青色渐变
- 圆角: 8px
- 字体加粗: 600

### 卡片设计
- 边框: 1px 深灰色
- 圆角: 12px
- 内边距: 20px
- 微妙阴影

### 输入框
- 深色背景
- 青色边框
- 圆角: 8px
- 焦点时高亮
