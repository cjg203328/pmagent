## ⚙️ 配置API密钥（重要！）

### 步骤1：获取API密钥

**使用 Claude (推荐):**
1. 访问 https://console.anthropic.com/
2. 注册/登录账号
3. 创建 API Key

**使用 OpenAI:**
1. 访问 https://platform.openai.com/
2. 注册/登录账号
3. 创建 API Key

### 步骤2：配置密钥

一键启动脚本会自动创建 `.env` 文件，然后：

**Windows用户：**
- 脚本会提示是否打开 .env 文件
- 选择 Y，会自动用记事本打开

**手动编辑：**
用任意文本编辑器打开 `.env` 文件，填入：

```env
# 使用 Claude (推荐)
LLM_PROVIDER=anthropic
ANTHROPIC_API_KEY=sk-ant-your-actual-key-here

# 或使用 OpenAI
# LLM_PROVIDER=openai
# OPENAI_API_KEY=sk-your-actual-key-here
```

保存文件后，再次运行启动脚本即可！

## 🛠️ 如果遇到问题

### 问题1：没有配置API密钥

```
ValueError: ANTHROPIC_API_KEY not found
```

**解决：**
1. 编辑 `.env` 文件
2. 填入正确的API密钥
3. 重新运行启动脚本

### 问题2：端口被占用

```
Port 8501 is already in use
```

**解决：**
```bash
# 使用其他端口
streamlit run app.py --server.port 8502
```

### 问题3：依赖安装失败

**解决：**
```bash
# 手动安装
pip install streamlit anthropic openai python-dotenv
```
